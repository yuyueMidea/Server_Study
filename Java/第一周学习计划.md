# 7、封装（非常重要）

真实项目几乎都这样：

```java

    this.name = name;
}
```

# 六、Day5：Lambda + Stream（现代Java重点）

现代 Java 业务代码超级多。

---

# 1、Lambda

```java
users.forEach(user -> {
    System.out.println(user.getName());
});
```

类似 JS：

```js
users.forEach(user => {})
```

---

# 2、filter

```java
users.stream()
     .filter(user -> user.getAge() > 18)
```

---

# 3、map

```java
users.stream()
     .map(User::getName)
```

---

# 4、collect

```java
.collect(Collectors.toList())
```

---

# 5、完整示例

```java
List<String> names = users.stream()
    .filter(u -> u.getAge() > 18)
    .map(User::getName)
    .collect(Collectors.toList());
```
